Overview



This project is an Ultrasonic Power Circuit designed to drive an ultrasonic transducer using a high-frequency excitation signal.

The system includes:



A high-frequency driver stage for the ultrasonic crystal.



A digitally controlled boost converter, where the output power can be adjusted using PWM signals from a microcontroller (MCU).



A touch-amplification circuit that improves user control and enhances power delivery.



This PCB is implemented using Altium Designer with a 2-layer layout optimized for signal integrity and power handling.



⚙️ Main Features

🔹 1. Ultrasonic Excitation Stage



Generates a high-frequency AC signal to drive the ultrasonic crystal.



Optimized layout for minimizing losses and improving waveform quality.



Designed for stable resonance operation.



🔹 2. MCU-Controlled Boost Converter



Adjustable output using an MCU via PWM control.



Enables dynamic power control depending on application needs.



Efficient conversion and thermal management on 2-layer PCB.



🔹 3. Touch Amplification Circuit



Enhances the drive signal based on user interaction.



Provides controlled amplitude boost.



Integrated protection features.
